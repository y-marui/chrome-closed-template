# assets/

ビルド・実行時には使用しない、非ソースコードの補助ファイルを置く。

> このファイルは正本（日本語版）です。

- `archive/` — 過去のアイコンデザイン等、現在は使われていない旧版の保管場所。参照専用で、
  どのドキュメント・コードからもリンクされない

## Store Image Workflow

ストア画像の置き場は次に統一する。ディレクトリは素材が必要になったときに作る。

| 場所 | 用途 |
| --- | --- |
| `docs/store/<platform>/screenshots/` | 現在掲載する、確認済み・規定サイズのスクリーンショットだけ |
| `docs/store/<platform>/promotional/` | 現在使用する、確認済みのプロモーション画像 |
| `assets/store/<platform>/sources/` | 撮影元・編集元の素材 |
| `assets/store/<platform>/candidates/` | 加工中・未採用・表示不具合を含む候補 |
| `assets/store/<platform>/archive/` | 差し替え済みの旧掲載画像 |

1. 撮影元を `sources/` に置き、必要な縮小・形式変換をして `candidates/` で確認する。
2. 内容・言語・タグライン・バージョン・寸法を確認し、採用画像だけを `docs/store/` に置く。
3. 差し替えた旧掲載画像は同名のまま `archive/` に移す。未採用画像は `candidates/` に残す。
4. 掲載順と使用ファイルは `docs/store/<platform>/README.md` に明記する。

新規ファイル名は `YYYY-MM-DD_01-en-engines.png` のように撮影日・掲載順・言語・画面名を含める。
既存の採用画像は命名変更だけを目的に改名しない。同名で別画像を上書きせず、必要なら時刻等を追加する。
FirefoxでChromeの画像を流用する場合は、コピーせずFirefox側のREADMEから採用画像を参照する。
素材は拡張機能のZIPに含めない。原寸画像を保存するために容量制限や秘密情報の検査を回避しない。
不要候補や撮影元の削除は明示依頼時に行う。移動・採用だけを理由に元画像を削除しない。
